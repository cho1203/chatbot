# 6.1 공구길이보정 Shift Type 개요
출처: FANUC PROGRAMMING B-64484KO-2/02, 6장 보정기능, 6.1, p.137.
공구길이 Offset 동작을 Program 좌표계 Shift로 실현할 수 있습니다. 공구길이보정이 걸리는 축의 좌표계를 공구길이 보정량만큼 Shift 합니다.
Parameter TOS(No.5006#6) 또는 Parameter TOP(No.11400#2)로 공구길이보정 Shift Type을 선택할 수 있습니다.
G43, G44 또는 G49 지령에 이동지령이 없으면 축은 이동하지 않습니다. 이동지령이 있으면 좌표계가 Shift된 뒤 축이 이동합니다.
공구길이보정은 축 종류에 따라 세 가지입니다.
A: Z축 방향 공구길이 값을 보정합니다.
B: X축, Y축, Z축 방향 여러 개의 공구길이 값을 보정합니다.
C: 지정된 축 방향 공구길이 값을 보정합니다.

# 공구길이보정 A 형식
출처: B-64484KO-2/02 6.1, p.137.
G43 Z_ H_ ; Z축 방향으로 보정량만큼 +측으로 좌표계 Shift
G44 Z_ H_ ; Z축 방향으로 보정량만큼 -측으로 좌표계 Shift
G43(또는 G44): 공구길이보정 개시 +(또는 -)측 Offset
H_: 공구길이 보정량 지정 Address

# 공구길이보정 B 형식
출처: B-64484KO-2/02 6.1, p.138.
평면 선택과 함께 지정합니다.
G17 G43 Z_ H_ ; Z축 방향으로 보정량만큼 +측으로 좌표계 Shift
G17 G44 Z_ H_ ; Z축 방향으로 보정량만큼 -측으로 좌표계 Shift
G18 G43 Y_ H_ ; X축 방향으로 보정량만큼 +측으로 좌표계 Shift
G18 G44 Y_ H_ ; X축 방향으로 보정량만큼 -측으로 좌표계 Shift
G19 G43 X_ H_ ; Y축 방향으로 보정량만큼 +측으로 좌표계 Shift
G19 G44 X_ H_ ; Y축 방향으로 보정량만큼 -측으로 좌표계 Shift
G17(또는 G18, G19): 평면선택
G43(또는 G44): 공구길이보정 개시 +(또는 -)측 Offset
H_: 공구길이 보정량 지정 Address

# 공구길이보정 C 형식
출처: B-64484KO-2/02 6.1, p.138.
G43 α_ H_ ; 지정축 방향으로 보정량만큼 +측으로 좌표계 Shift
G44 α_ H_ ; 지정축 방향으로 보정량만큼 -측으로 좌표계 Shift
α_: 임의의 1축 Address
H_: 공구길이 보정량 지정 Address

# 공구길이보정 Cancel
출처: B-64484KO-2/02 6.1, p.138.
G49 또는 H0 ; 공구길이보정 Cancel
G49(또는 H0): 공구길이보정 Cancel
Offset을 Cancel하면 좌표계 Shift가 원래대로 돌아갑니다. 이때 이동지령이 없으면 축은 이동하지 않습니다.

# 공구길이보정 해설
출처: B-64484KO-2/02 6.1, p.138.
Offset 방향: H Code로 지정된 Offset Memory 설정값입니다. G43일 때는 +측, G44일 때는 -측으로 좌표계가 Shift 됩니다. 공구길이보정 보정량의 부호가 음이면 각각 역방향이 됩니다. G43, G44는 Modal G Code로 동일 Group내의 다른 G Code가 지령될 때까지 유효합니다.
H Code는 지정된 번호(Offset 번호)에 대응하는 Offset Memory 설정값입니다. Offset 번호 0에 대응하는 공구길이보정은 통상 0을 의미합니다. H0에 대응하는 공구길이 보정량은 설정할 수 없습니다.
보정축은 공구길이보정 A/B/C 중 하나를 Parameter TLC, TLB(No.5001#0,#1)로 지정합니다.
공구길이보정 B에서는 복수의 Block에서 Offset축을 지정하면 2축 이상의 Offset이 가능합니다. 예: G19 G43 H_ 는 X축을 Offset, G18 G43 H_ 는 Y축을 Offset.
공구길이보정 C에서 Parameter TAL(No.5001#3)을 1로 설정하면 동시에 2축 이상 Offset 해도 Alarm이 발생하지 않도록 할 수 있습니다.

# 공구길이보정 개시 Cancel 제한
출처: B-64484KO-2/02 6.1, p.139.
공구길이보정 Shift Type을 사용할 때(Parameter TOS No.5006#6=1 또는 Parameter TOP No.11400#2=1) 공구경보정 등의 Mode 중에는 공구길이보정 개시 또는 Cancel이 지령되어도 개시 또는 Cancel이 지령된 Block이 종료될 때까지 이후 Block 선독을 실행하지 않습니다.
개시 또는 Cancel 지령된 Block에서 일단 감속 정지합니다.
선독되지 않으므로 공구경보정의 보정 Vector는 개시 또는 Cancel 지령된 직전 Block에 수직인 Vector가 됩니다. 이 때문에 이 지령 전후에서 절입과다나 절입부족이 발생할 수 있습니다.
개시 또는 Cancel 지령된 Block이 완료될 때까지 다음에 지령한 Custom Macro는 실행되지 않습니다.
다음 지령에서는 Block 선독을 하지 않습니다. Group 07의 G Code가 G40 이외인 경우(공구경보정 G41/G42, 3차원 공구경보정, Smooth 보간 G05.1 Q2 Mode 중인 경우).
공구길이보정(G43/G44), 공구축방향 공구길이보정(G43.1), 공구선단점제어(G43.4/G43.5)도 해당합니다.

# 공구경보정 중 절입과다 설명
출처: B-64484KO-2/02 6.1, p.139-140. 그림은 넣지 않고 설명만 적습니다.
공구경보정 Mode 중 공구길이보정 개시 또는 Cancel을 실행하면 절입과다가 발생할 수 있습니다.
발생 예: G41/G42 Mode 중에 G43(공구길이보정 개시)이 있으면 그 이후 Block을 선독하지 않습니다. N2-N3 사이에서 일단 감속 정지하고, N1 종점의 공구경보정 Vector가 N1 Block에 수직이 됩니다. 절입과다가 될 수 있습니다. 매뉴얼 그림은 선독하지 않을 때의 공구경보정 Vector와 공구중심경로가 Program 지령 경로에서 어떻게 어긋나는지를 보여 줍니다.
발생하지 않는 예: 공구경보정 Mode 전에 공구길이보정을 개시해 둡니다. 공구길이보정 개시 지령이 공구경보정 Mode가 아니면 이후 Block은 선독되고, 공구경보정 경로는 올바르게 구해집니다.

# H코드로 공구길이 보정량 변경
출처: B-64484KO-2/02 6.1, p.141.
공구길이보정 Mode 중에 Offset 번호를 변경했을 때의 동작입니다.
Parameter MOF(No.5000#1)=0 이면 N6 Block에서 공구길이 보정량이 변경된 양만큼 축이 이동합니다.
Parameter MOF(No.5000#1)=1 이면 N6 Block에서는 이동이 실행되지 않고, Incremental 지령이 있으면 공구길이 보정 변환량만큼의 이동은 실행되지 않습니다. Absolute 지령으로 보정축을 지령한 Block에서 공구길이 보정량 변경만큼 이동합니다.

# 운전중 공구길이 보정량을 지령할 때
출처: B-64484KO-2/02 6.1, p.141.
Parameter EVO(No.5001#6)=1로 Program을 연속운전으로 실행하고, 실행 중에 공구길이보정 번호를 변경한 경우입니다.
Parameter MOF(No.5000#1)=0 이면 공구보정량을 변경한 후 최초로 Buffering 된 Block에서 공구길이 보정량 변경만큼 축이 이동합니다.
Parameter MOF(No.5000#1)=1 이면 변경 후 최초 Buffering Block이지만 그 Block에 보정축 지령이 없으면 공구길이 보정량 변경만큼의 이동은 실행되지 않습니다. Incremental 지령만 있으면 보정 변경량 이동은 실행되지 않고, 최초로 지령된 보정축 Absolute 지령에서 변경량만큼 이동합니다.
